---
title: Partas.AnimeJs
---

Build typed, reusable AnimeJs options in F#, then start effects explicitly. The generated
DSL targets AnimeJs **4.5.0** and shares CSS, DOM, SVG and ECMAScript types with Xantham.

Start with the [compiled getting-started example](../../examples/GettingStarted.fs), read the
[migration guide](migration.md), or browse the [API reference](/reference/index.md).

Install `Partas.AnimeJs`, `Xantham.Fable.Core` and `Xantham.Fable.Core.TS` from the
documented NuGet sources and install `animejs@4.5.0` with your JavaScript package manager.
Compile your project with Fable. Consumers do not run the generator or repository CLI.
